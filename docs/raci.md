# RACI Matrix

Матрица ответственности по задачам проекта для всех ролей команды.

Матрица RACI определяет распределение ответственности по ключевым областям проекта между ролями команды:

- SA/PO — Solution Architect / Product Owner
- AI Eng — AI Engineer
- MLOps — MLOps Engineer
- Fullstack — Fullstack Developer

Для каждой области указаны роли RACI:

- R (Responsible) — непосредственно выполняет задачу
- A (Accountable) — несёт окончательную ответственность за результат
- C (Consulted) — консультируется по задаче (двусторонняя коммуникация)
- I (Informed) — информируется о ходе/результатах (односторонняя коммуникация)

**Decision Making Process (Процесс принятия решений)**

- Окончательное решение по бизнес-требованиям, приоритетам, scope и архитектуре принимает SA/PO.
- По техническим вопросам в своей области (например, выбор модели, настройка CI/CD, структура API) решение принимает участник с ролью Responsible (R) после консультации с командой.
- Все ключевые решения фиксируются в документации (в том числе в BookStack).

**Escalation Path (Путь эскалации)**

В случае разногласий или блокирующих ситуаций применяется следующий трёхшаговый процесс:

1. Обсуждение в команде — попытка достичь консенсуса в течение 24 часов.
2. Решение SA/PO — если согласие не достигнуто, SA/PO принимает окончательное решение.
3. Обращение к ментору — если решение SA/PO нарушает технические ограничения, сроки или принципы проекта, вопрос эскалируется ментору.
