# Прототип интерфейсов

## 1. Wireframes (Описание экранов)

| №   | Экран                  | Содержимое                                                     | Состояния                                                        |
| --- | ---------------------- | -------------------------------------------------------------- | ---------------------------------------------------------------- |
| 1   | Главная                | Кнопки «Сфотографировать», «Ввести вручную», поле ввода        | Успех (основной экран), Ошибка (не предоставлено разрешение)     |
| 2   | Результат анализа      | Список карточек рецептов, фильтры                              | Успех (результаты), Ошибка (не распознано), Пусто (нет рецептов) |
| 3   | Детали рецепта         | Название, фото, ингредиенты, шаги, метаданные                  | Загрузка (спиннер), Успех                                        |
| 4   | Избранное              | Список сохранённых рецептов                                    | Успех (есть рецепты), Пусто (нет сохранённых)                    |
| 5   | Редактирование рецепта | Редактируемые поля: название, ингредиенты, шаги, загрузка фото | Успех                                                            |
| 6   | Профиль                | Поля: имя, телефон, тема, диеты, аллергии                      | Успех                                                            |


## 2. Компонентная архитектура UI

### Иерархия компонентов

```
AppShell
└── ScreenLayout
    ├── Header (с кнопкой «Назад» или заголовком)
    ├── Content
    │    ├── RecipeCard (в списках)
    │    ├── RecipeDetail (на экране рецепта)
    │    │   ├── RecipeImage
    │    │   ├── MetaBar (время, калории)
    │    │   ├── IngredientList
    │    │   │   └── IngredientItem
    │    │   └── StepList
    │    │       └── StepItem
    │    ├── ProfileForm
    │    │   ├── TextInput
    │    │   ├── ThemeSelector
    │    │   ├── TagGroup (диеты/аллергии)
    │    │   └── Tag
    │    └── EditableRecipeForm
    │        ├── EditableTitle
    │        ├── IngredientList (редактируемая)
    │        │   └── IngredientItem (с кнопками +/−)
    │        └── StepList (редактируемая)
    │            └── StepItem (редактируемый)
    └── BottomNavigation (только на основных экранах)
```

### Описание ключевых компонентов

| Компонент              | Назначение                                                                                | Используется в                                           |
| ---------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| **`RecipeCard`**       | Мини-карточка рецепта: изображение, название, время, калории                              | Экран «Результат анализа», «Избранное»                   |
| **`IngredientItem`**   | Элемент ингредиента: текст + (в режиме редактирования) кнопки удаления/редактирования     | «Детали рецепта», «Редактирование»                       |
| **`StepItem`**         | Пошаговый пункт: номер (в просмотре) или текстовое поле (в редактировании)                | «Детали рецепта», «Редактирование»                       |
| **`Tag`**              | Интерактивный тег для диет/аллергий: «Веган», «Орехи» и т.д.                              | «Профиль»                                                |
| **`Header`**           | Шапка экрана: кнопка «Назад» + заголовок. На временных экранах — с «←», на основных — без | Все временные экраны (результат, рецепт, редактирование) |
| **`BottomNavigation`** | Нижняя панель с иконками: Главная / Избранное / Профиль                                   | Только основные экраны (Главная, Избранное, Профиль)     |
| **`ActionButton`**     | Кнопка с иконкой и подписью в нижней панели действий («Сохранить», «Оценить»)             | Экран «Детали рецепта»                                   |

## 3. Responsive дизайн

Приложение разрабатывается по принципу **mobile-first**:
- Основной фокус — мобильные устройства (ширина 375–414px)
- На desktop (≥768px) интерфейс адаптируется:
  - Карточки рецептов отображаются в 2 колонки вместо 1
  - Поля ввода и кнопки увеличиваются для удобства
  - Нижняя навигация остаётся внизу (не переходит в sidebar)

## 4. Состояния: загрузка, ошибка, успех

| Тип состояния | Когда используется                        | Визуальный паттерн                |
| ------------- | ----------------------------------------- | --------------------------------- |
| **Загрузка**  | Ожидание ответа от AI или загрузки данных | Центрированный спиннер + текст    |
| **Успех**     | Основное состояние экрана                 | Полный контент без предупреждений |
| **Ошибка**    | Сбой в распознавании или сети             | Иконка ⚠️ + пояснение + CTA       |
| **Пусто**     | Нет данных для отображения                | Иконка + пояснение + CTA          |
