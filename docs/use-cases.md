# Use-case Narrative

Детальное описание пользовательских сценариев с альтернативными путями

## Happy Path

Основной успешный сценарий

1. Пользователь открывает приложение.
2. Пользователь вводит список имеющихся продуктов в текстовое поле или делает фото.
3. Нажимает "Подобрать".
4. Система анализирует ингредиенты.
5. Система отображает результат в виде карточек.
6. Пользователь просматривает варианты, выбирает подходящий рецепт.
7. Система открывает полную инструкцию с пошаговыми фото.
8. Пользователь начинает готовить.

## Alternative Flows

### AF1: Частичное совпадение ингредиентов

**Условие:** Пользователь ввёл 5 продуктов, но система предложила только 2.  
**Поток:**

1. Система анализирует список и находит совпадения только для части ингредиентов.
2. Отображает сообщение: «Найдены рецепты по 2 из 5 продуктов».
3. Предлагает блюда, использующие распознанные продукты + базовые (соль, перец, вода).
4. Пользователь может выбрать рецепт или уточнить список.

### AF2: Неизвестный или неподдерживаемый ингредиент

**Условие:** Пользователь ввёл «трюфельное масло», которого нет в базе.  
**Поток:**

1. Система не находит точного совпадения.
2. Предлагает замену: «Использовать оливковое масло вместо трюфельного?»
3. Пользователь подтверждает или редактирует ввод.

## Error Handling

### EH1: Пустой или некорректный ввод

**Условие:** Пользователь отправил пустой запрос или ввёл несуществующее слово (например, «капртошка»).  
**Поток:**

1. Система проверяет, что список не пуст.
2. Если пуст — показывает: «Введите хотя бы один продукт».
3. Пользователь редактирует ввод.

### EH2: Технический сбой (отсутствие интернета / недоступность API)

**Условие:** Запрос к серверу невозможен.  
**Поток:**

1. Система обнаруживает отсутствие подключения.
2. Отображает уведомление: «Офлайн-режим: показаны последние сохранённые рецепты».
3. Показывает до 3 последних просмотренных рецептов из кэша.

### EH3: Превышение лимита ингредиентов (>10)

**Условие:** Пользователь ввёл 25 ингредиентов.  
**Поток:**

1. Система ограничивает обработку первыми 10 продуктами.
2. Показывает уведомление: «Для точного результата используйте до 10 ингредиентов».
3. Продолжает поиск по усечённому списку.

## User Value

Ценность для пользователя

- **HP:** Экономия 15–20 минут на поиск рецепта, снижение пищевых отходов за счёт использования имеющихся продуктов, повышение уверенности в кулинарных навыках благодаря чёткой инструкции.
- **AF1:** Пользователь не получает «ничего не найдено» и сохраняет мотивацию к использованию приложения.
- **AF2:** Повышает гибкость системы и снижает барьер для новых пользователей.
- **EH1:** Снижает количество неудачных попыток и повышает доверие к системе.
- **EH2:** Обеспечивает базовую функциональность даже при сбое, удерживая пользователя.
- **EH3:** Ускоряет ответ системы и улучшает релевантность результатов.
