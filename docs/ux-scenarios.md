# UX-сценарии

## 1. User Journey по Use Cases

### UC1: Подбор рецепта  
**Цель**: Получение рецептов на основе фото продуктов.

#### Happy Path

| № | Действие пользователя | Действие системы / UI |
|---|------------------------|------------------------|
| 1 | Нажимает «Сфотографировать» | Кнопка даёт визуальную обратную связь (лёгкое увеличение) |
| 2 | Делает фото | Открывается камера → Съёмка → Загорается кнопка «Подтвердить» |
| 3 | Нажимает «Подтвердить» | Отображается спиннер + текст: *«Анализируем продукты…»* |
| 4 | Ожидает | Система отправляет фото в VLM → получает ингредиенты → передаёт в LLM → генерирует рецепты → Рецепты отображаются |
| 5 | Пролистывает карточки с рецептами | — |

#### Edge Cases
- **AF1: Ввод вручную** → вводит ингридиенты вручную; загорается кнопка «Подтвердить».
- **AF2: Несколько фото** → после первого фото появляется кнопка **«+ Добавить фото»**.
- **AF3: Редактирование списка** → ингредиенты отображаются как теги с крестиком (×) для удаления и плюсиком (+) для добавления.

#### Ошибки
- **EH1: Плохое фото** → иконка + текст *«Качество фото низкое. Переснимите.* + кнопка **«Повторить»**.
- **EH2: Нет продуктов** → иконка + текст *«Не найдено продуктов»* + кнопка **«Ввести вручную»**.



### UC2: Сохранить понравившийся рецепт  
**Цель**: Сохранение рецептов для удобства в будущем.

#### Happy Path

| № | Действие пользователя | Действие системы / UI |
|---|------------------------|------------------------|
| 1 | Просматривает список рецептов | Отображаются карточки с превью, названием, временем, калориями |
| 2 | Нажимает «Сохранить» на рецепте | Иконка становится красной + появляется тост: *«Сохранено!»* |


#### Edge Cases
- **AF1: Категории** → при первом сохранении появляются базовые категории на выбор: *«Первое»*, *«Второе»* и тд.

#### Ошибки
- **EH1: Нет интернета** → тост: *«Сохранено.*.
- **EH2: Уже сохранён** → иконка красная, тост: *«В избранном»*.



### UC3: Просмотреть сохранённые рецепты  
**Цель**: Удобное отображение понравившихся рецептов.

#### Happy Path

| № | Действие пользователя | Действие системы / UI |
|---|------------------------|------------------------|
| 1 | Переходит в «Избранное» | Отображается сетка карточек сохранённых рецептов |
| 2 | Пролистывает список | Карточки загружаются постепенно |
| 3 | Нажимает на рецепт | Переход на экран рецепта |

#### Edge Cases
- **AF1: Поиск** → в шапке появляется поле поиска при прокрутке вниз.
- **AF2: Категории** → фильтр по категориям в шапке.

#### Ошибки
- **EH1: Пусто** → текст *«Нет сохранённых рецептов»* + кнопка **«Найти рецепты»**.



### UC4: Оценить рецепт  
**Цель**: Обратная связь.

#### Happy Path

| № | Действие пользователя | Действие системы / UI |
|---|------------------------|------------------------|
| 1 | Открывает рецепт | Отображается полный рецепт: ингредиенты, шаги, метаданные |
| 2 | Нажимает на звёзды | Звёзды подсвечиваются жёлтым |
| 3 | — | Оценка сохраняется локально |

#### Edge Cases
- **AF1: Изменение оценки** → при повторном нажатии на звёзды также открывается выбор.

#### Ошибки
- **EH1: Некорректный ввод** → попытка поставить 6 звёзд игнорируется.



### UC5: Поделиться рецептом  
**Цель**: Возможность делится рецептом со знакомыми и близкими.

#### Happy Path

| № | Действие пользователя | Действие системы / UI |
|---|------------------------|------------------------|
| 1 | Открывает рецепт | Отображается экран с кнопкой «Поделиться» |
| 2 | Нажимает «Поделиться» | Генерируется карточка |
| 3 | Выбирает способ | Открывается соответствующее приложение |

#### Edge Cases
- **AF1: Картинка** → генерируется PNG.
- **AF2: Текст** → генерируется файл с названием, описанием и временем.

#### Ошибки
- **EH1: Ошибка генерации** → отправляется стандартная карточка: *«Рецепт: [название]. Время: [X] мин»*.



### UC6: Сменить тему  
**Цель**: Выбор предпочтительного внешнего вида.

#### Happy Path

| № | Действие пользователя | Действие системы / UI |
|---|------------------------|------------------------|
| 1 | Заходит в «Профиль» → прокручивает до «Тема» | Отображается раздел с переключателем |
| 2 | Нажимает [Тема] | Интерфейс переключается → Элементы адаптируются под другую тему|

#### Edge Cases
- **AF1: Авто** → тема меняется в 6:00 и 22:00 автоматически.
- **AF2: Ночной режим** → тёмная тема включается только после 22:00.

#### Ошибки
- **EH1: Сбой темы** → приложение перезагружает UI.








## 2. Точки взаимодействия с LLM

| Use Case | Этап | Технология | Входные данные | Выходные данные |
|----------|------|------------|----------------|------------------|
| UC1 | Распознавание | VLM (Visual Language Model) | Фото продуктов | JSON: `["яйцо", "помидор", "сыр"]` |
| UC1 | Генерация | LLM (Large Language Model) | Список ингредиентов | Рецепты с шагами, временем, калориями |

## 3. Микроинтеракции и обратная связь

| Элемент | Поведение |
|--------|----------|
| Кнопка «Сфотографировать» | Лёгкое увеличение при нажатии |
| Иконка «Сохранить» | Смена цвета + тост «Сохранено!» |
| Звёзды оценки | Подсветка звёзд слева от курсора |
| Спиннер загрузки | Вращение → появление результатов |
| Ошибка распознавания | Текст ⚠️ + кнопка «Повторить» |
| Переключатель темы | Переход между цветовыми схемами |
| Тег ингредиента | При удалении — исчезновение |
